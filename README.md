# E-Commerce Customer Segmentation using K-Means

## 📌 Project Overview

This project focuses on analyzing e-commerce customer behavior and grouping customers into meaningful segments using the **K-Means Clustering** algorithm.

The project uses the **Online Retail Dataset** and **Orange Data Mining** to perform data analysis, preprocessing, and customer segmentation.

## 🎯 Objectives

- Analyze customer purchasing behavior.
- Identify meaningful customer groups.
- Apply K-Means clustering for customer segmentation.
- Visualize and interpret the resulting clusters.
- Understand how clustering can support data-driven business decisions.

## 🛠️ Tools & Technologies

- **Orange Data Mining**
- **K-Means Clustering**
- **Microsoft Excel**
- **Data Visualization**
- **Data Preprocessing**

## 📊 Dataset

The project uses the **Online Retail Dataset**, which contains transactional information from an online retail business.

The dataset includes information such as:

- Customer ID
- Invoice information
- Product details
- Quantity
- Unit Price
- Transaction information

## 🔄 Methodology

The project follows these major steps:

1. **Data Collection**
2. **Data Preprocessing**
3. **Customer Data Preparation**
4. **Feature Selection**
5. **K-Means Clustering**
6. **Cluster Analysis**
7. **Result Interpretation**

## 🤖 K-Means Clustering

K-Means clustering is an unsupervised machine learning algorithm that divides data into a predefined number of clusters.

In this project, customers are divided into **4 clusters** based on their purchasing characteristics.

The clustering configuration includes:

- **Number of Clusters:** 4
- **Normalization:** Enabled
- **Initialization:** KMeans++
- **Re-runs:** 10
- **Maximum Iterations:** 300

## 📈 Results

The K-Means model successfully groups customers into four different segments.

These segments can be analyzed to understand differences in customer purchasing behavior and identify patterns within the dataset.
